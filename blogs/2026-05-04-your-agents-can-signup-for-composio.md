# Your agents can sign up for Composio

**Author:** Rahul Tarak
**Date:** May 4, 2026
**Reading Time:** 1 min

---

Composio has prioritized agent experience since its inception. The platform recently expanded beyond developer tools to improve the experience for everyday users through products like Rube, now integrated into Composio For You.

The latest development takes this further: agents can now autonomously create their own Composio accounts. These accounts are fully functional and anonymous, remaining claimable by users later if needed. According to the announcement: "Your agent can sign up for its own Composio account. Anonymous, full-featured, claimable by you later if it does anything worth keeping."

Agents can access these accounts through multiple methods including the CLI, MCP, or by using the API key directly. The feature enables agents to leverage the same capabilities available to human users.

To explore this capability, users are invited to visit `agents.composio.dev` and request agent account creation through their preferred agent interface.
